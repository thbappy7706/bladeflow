## [Unreleased]

### Added
- Built-in navigation progress indicator (top loading bar with a modern Indigo-to-Cyan gradient and glow effect).
- Toggle option to disable the default loader using `data-bladeflow-progress="false"` on the content wrapper element.
- Custom navigation lifecycle events (`bladeflow:start`, `bladeflow:finish`, and `bladeflow:error`) to support custom loading transitions, overlays, or trackers.
